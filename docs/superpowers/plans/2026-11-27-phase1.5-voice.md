# Phase 1.5: Voice Dictation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Click the mic (or press `Ctrl+M`) in the capture box, speak, and get the transcribed text in the input with the normal parse preview, transcribed locally by whisper.cpp.

**Architecture:** The webview records the mic (`getUserMedia` + an AudioWorklet), resamples to 16 kHz mono Int16 PCM, runs a simple RMS voice-activity detector for auto-stop, and sends the PCM (base64) to a new bound Go service. A new `internal/voice` package downloads and verifies the pinned engine and model (after in-app consent), and runs whisper.cpp as a subprocess. On platforms with an official prebuilt engine it uses `whisper-server`, started when listening starts (so the model loads while the user speaks) and killed after 30 s idle. Elsewhere it falls back to a system `whisper-cli`, one process per dictation.

**Tech Stack:** Go 1.26 (stdlib `net/http`, `archive/zip`, `archive/tar`, `crypto/sha256`, `os/exec`, `golang.org/x/sys/windows`), Wails v3.1.0 bindings and events, vanilla TS, Web Audio API, Lucide icons.

**Spec:** `docs/superpowers/specs/2026-11-27-awesome-reminder-design.md` ("1.5. Voice dictation"), `docs/superpowers/specs/2026-11-27-ui-design-guide.md` ("Listening state").

## Global Constraints

- Zero cost; transcription is local; CPU only; whisper threads = `max(1, min(8, NumCPU/2))`.
- No model in RAM when not dictating: the whisper process is started by `Warm`/`Transcribe` only and exits 30 s after its last use, on app quit, and (Windows job object / Linux `Pdeathsig`) if the app dies.
- Nothing is downloaded without an explicit click on the consent panel; every download is verified against a pinned SHA-256 and size before use.

### Packaging decision per OS

- **Windows x64:** official prebuilt (`whisper-bin-x64.zip`). It links the MSVC runtime and OpenMP (`msvcp140`, `vcruntime140`, `vcruntime140_1`, `vcomp140`), which the zip does not ship. The app checks `System32` for them and, if one is missing, shows "Install the Microsoft Visual C++ Redistributable (x64)" with the `https://aka.ms/vs/17/release/vc_redist.x64.exe` link instead of offering the download.
- **Linux x64/arm64:** official prebuilt Ubuntu tarballs (built on Ubuntu 22.04, so a glibc of that age or newer is needed); started with `LD_LIBRARY_PATH` set to the engine folder.
- **macOS (and any other OS/arch):** whisper.cpp publishes no macOS CLI binaries, and Homebrew's `whisper.cpp` formula builds with `-DWHISPER_BUILD_SERVER=OFF`. The app looks for a system `whisper-server`, then `whisper-cli`, on `PATH` and in `/opt/homebrew/bin` and `/usr/local/bin`. The README says `brew install whisper.cpp`. With `whisper-cli` each dictation spawns one short-lived process (no warm start). The model is still downloaded by the app with consent. A CI-built macOS engine is deferred until there is a release pipeline; Info.plist gets `NSMicrophoneUsageDescription`.

## Review Focus

1. **The capture window loses focus while listening** (it hides on blur): the mic must be released and the recording dropped, with no stray "Transcribing" when it reopens. Test: Task 7 manual step "blur while listening".
2. **A partial or tampered download** (network drop, wrong bytes, app quit mid-download): no file is left at the final path and the next Status is "absent" again. Test: `TestDownloadChecksumMismatchLeavesNothing`, `TestDownloadCancelled`, `TestInstallFailureReportsError` (Tasks 1, 5).
3. **The whisper process dies or never becomes ready** (missing DLL, bad model, port taken): Transcribe returns an error the box shows inline, and the next dictation starts a fresh process. Test: `TestServerEngineRestartsAfterCrash`, `TestServerEngineStartFailure` (Task 4).
4. **Silence or a cough** (whisper returns `[BLANK_AUDIO]` or nothing): the input stays unchanged and the box says "Didn't catch that". Test: `TestCleanTranscript` blank cases (Task 3) and the empty-result branch in Task 7.
5. **Mic denied or no device** (`NotAllowedError`, `NotFoundError`, `NotReadableError`): an inline message under the input names the fix (Windows privacy settings), nothing else breaks. Test: Task 7 manual step with the Windows microphone privacy toggle off.
